Tổng quan Hệ thống & Base URL

Booking System Backend được xây dựng trên nền tảng Cloudflare Edge Workers (Compute) kết hợp Supabase PostgreSQL (ACID Relational Core) và Google Drive API (Lưu trữ không giới hạn). Hệ thống hỗ trợ xử lý Stream Byte-Range 206, mã hóa xác thực OTP không trạng thái (Stateless HMAC-SHA256), và tự động xóa dọn tệp tin khi xóa bản ghi dữ liệu.

API / Google Drive / Stream Media File

1. Stream Media File từ Google Drive

Truy xuất và phát trực tiếp luồng nhị phân (ảnh, PDF, video, audio) từ Google Drive thông qua Cloudflare Edge Worker. Hỗ trợ đầy đủ HTTP 206 Partial Content (Byte-Range Requests).

GET / HEAD /api/drive/file/:fileId
Path Parameters
Tham số Kiểu Bắt buộc Mô tả
fileId string Bắt buộc ID tệp tin Google Drive (Ví dụ: 1g9K8x_XYZ9876)
API / Google Drive / Thumbnail

2. Lấy Thumbnail Tối ưu từ Google Cache

Truy xuất ảnh thu nhỏ đã nén sẵn từ CDN Google với các tùy chọn kích thước linh hoạt, giảm băng thông tải ảnh trong danh sách bất động sản.

GET /api/drive/thumbnail/:fileId
Query Parameters
Tham số Kiểu Mặc định Mô tả
sz string s400 Độ phân giải thumbnail (s400, s800, w1200)
API / Google Drive / Upload Stream

3. Tải lên Tệp tin (Streaming Multipart)

Tải lên trực tiếp nhị phân file vào Google Drive, tự động tạo và định tuyến thư mục theo Category và Entity ID.

POST /api/upload
HTTP Headers
Header Kiểu Bắt buộc Mô tả
Content-Type string Bắt buộc MIME type của file (Ví dụ: image/jpeg, application/pdf)
X-File-Name string Bắt buộc Tên file URL-encoded (Ví dụ: photo_01.jpg)
X-Category string Tùy chọn properties hoặc users
X-Sub-Category string Tùy chọn identification, contracts, payments
X-Entity-Id string Tùy chọn Tên hoặc mã định danh của đối tượng (Bất động sản hoặc Khách thuê)
X-Period string Tùy chọn Kỳ thanh toán (Ví dụ: Thang_08_2026)
API / Google Drive / Batch Delete

4. Xóa Tệp tin Hàng loạt & Thư mục Đối tượng

Xóa vĩnh viễn danh sách file ID và/hoặc toàn bộ thư mục của một đối tượng bị xóa trong database (tự động dọn dẹp sạch sẽ tài nguyên Drive).

POST /api/drive/delete
Request Body (JSON)
Trường dữ liệu Kiểu Mô tả
fileIds string[] Mảng các Google Drive File ID cần xóa
category string properties | users
entityId string Mã định danh thư mục cần xóa toàn bộ
API / Xác thực / Yêu cầu OTP

5. Yêu cầu Gửi mã OTP Xác thực

Tạo mã xác thực 6 chữ số ngẫu nhiên, ký token mật mã HMAC-SHA256 (thời hạn 5 phút), và gửi OTP qua Gmail SMTP TLS trực tiếp.

POST /api/request-otp
Request Body (JSON)
Trường Kiểu Bắt buộc Mô tả
contact string Bắt buộc Email hoặc số điện thoại nhận mã OTP
API / Xác thực / Kiểm tra OTP

6. Xác thực mã OTP

Kiểm tra tính hợp lệ của mã OTP người dùng nhập đối chiếu với chữ ký mật mã trong otpToken mà không cần lưu trữ session ở database.

POST /api/verify-otp
Request Body (JSON)
Trường Kiểu Bắt buộc Mô tả
contact string Bắt buộc Email hoặc số điện thoại đã yêu cầu OTP
otp string Bắt buộc Mã 6 chữ số người dùng nhập
otpToken string Bắt buộc Token HMAC nhận được từ bước yêu cầu OTP
